## Anthropic Messages API

Official source checked: https://platform.claude.com/docs/en/build-with-claude/vision

Observed contract used by the implementation:

- Images are supplied as `image` content blocks in a user message.
- A base64 source uses `source.type = "base64"`, `source.media_type`, and `source.data`.
- Anthropic recommends placing the image block before the text block.
- Supported API image formats include JPEG, PNG, GIF, and WebP. Lazy Customs intentionally accepts only PNG, JPEG, and WebP uploads so animated content is excluded.
- The direct Claude API permits up to 10 MB per base64-encoded image and 8000 x 8000 pixels. Lazy Customs applies smaller local limits: 5 MB, 4096 pixels per edge, and 16 megapixels.
- Claude analyzes images but does not generate or edit image pixels.

## OpenAI Image API

Official source checked: https://developers.openai.com/api/docs/guides/image-generation

Observed contract used by the preserved implementation:

- `openai.images.generate` / `POST /v1/images/generations` returns base64 image data in `data[0].b64_json`.
- The Image API returns base64-encoded image data and supports PNG output.
- Lazy Customs continues decoding `data[0].b64_json` server-side and returning the existing PNG response to the browser.
